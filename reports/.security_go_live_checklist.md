# Security Go-Live Checklist

This checklist captures the items to review before moving from development to production.

## Infrastructure and Transport
- Enforce HTTPS at the edge (redirect HTTP to HTTPS).
- Enable HSTS with a safe rollout plan (short max-age first, then increase).
- Confirm TLS configuration and certificate renewal process.

## Rate Limiting and Abuse Protection
- Ensure real client IP is preserved behind reverse proxy/load balancer.
- Configure trusted proxies and use forwarded headers in the app or gateway.
- Define rate limit tiers for login, forgot-password, and other sensitive endpoints.
- Add burst limits and global caps for WebSocket connections.

## Authentication and Session Handling
- Verify token expiration and refresh behavior across web and WebSocket clients.
- Ensure WebSocket auth failures are handled in the client UI.
- Rotate secrets and confirm secure storage for SECRET_KEY and SMTP credentials.

## HTTP Security Headers
- Define Content Security Policy (CSP) for production.
- Keep X-Frame-Options, X-Content-Type-Options, Referrer-Policy, and Permissions-Policy enabled.
- Add a production CSP report-only mode before enforcing blocking rules.

## Data Protection and Privacy
- Confirm password reset links are short-lived and single-use.
- Ensure PII is not logged in production.
- Validate file upload limits, allowed types, and malware scanning if required.

## Observability and Incident Response
- Add alerting for auth failures and rate limit spikes.
- Ensure logs include request IDs and user IDs where appropriate.
- Define on-call and rollback procedures for security incidents.

## Testing and Verification
- Run integration tests for auth, forgot-password, and WebSocket flows.
- Perform basic security scans (dependency audit, SAST if available).
- Validate CORS configuration matches the production domain list.
